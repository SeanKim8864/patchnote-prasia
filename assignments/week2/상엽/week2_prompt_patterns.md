# 2주차 과제: 질의 설계 훈련

---

## 주제 1: 렐름 이전

| 버전 | 질문 | 바꾼 요소 |
| ---- | ---- | --------- |
| V1 | 렐름 이전 알려줘 | 기본 (없음) |
| V2 | 2025년 렐름 이전 이력 알려줘 | 기간 추가 |
| V3 | 2025년 렐름 이전 이력을 이전 가능 렐름 목록과 조건 포함해서 알려줘 | 대상 구체화 |
| V4 | 2025년 렐름 이전 이력을 날짜 / 이전 가능 렐름 / 주요 조건 컬럼으로 표 형식으로 정리해줘 | 출력방식 지정 |

**가장 좋은 버전: V4**

기간(2025년), 대상(이전 가능 렐름+조건), 출력방식(표)이 모두 명확해서 원하는 결과를 바로 얻을 수 있다. V1~V3은 AI가 무엇을 중심으로 답할지 스스로 판단해야 해서 결과가 들쭉날쭉하다.

## 주제 2: 유니버스리그

| 버전 | 질문 | 바꾼 요소 |
| ---- | ---- | --------- |
| V1 | 유니버스리그 정산 알려줘 | 기본 (없음) |
| V2 | 유니버스리그 시즌별 정산 일정 알려줘 | 대상 추가 (시즌 단위) |
| V3 | 유니버스리그 시즌13 라운드별 정산 날짜와 보상 알려줘 | 기간 구체화 (특정 시즌) |
| V4 | 유니버스리그 시즌13 전체 일정을 라운드 / 정산일 / 보상 컬럼으로 표로 정리해줘 | 출력방식 지정 |

**가장 좋은 버전: V4**

시즌 번호(기간), 라운드+보상(대상), 표(출력방식)가 명확하다. V1은 "정산"이 무슨 의미인지 AI가 모호하게 해석할 여지가 있다.

## 주제 3: 클래스 체인지

| 버전 | 질문 | 바꾼 요소 |
| ---- | ---- | --------- |
| V1 | 클래스 체인지 알려줘 | 기본 (없음) |
| V2 | 2025년 클래스 체인지 이력 알려줘 | 기간 추가 |
| V3 | 2025년 클래스 체인지 이력을 변경 가능한 아퀴룬 목록과 비용 기준으로 알려줘 | 대상 구체화 |
| V4 | 2025년 클래스 체인지 패치 이력을 날짜 / 변경 가능 아퀴룬 / 소모 비용 컬럼으로 표 형식으로 정리해줘 | 출력방식 지정 |

**가장 좋은 버전: V4**

날짜 범위(기간), 아퀴룬+비용(대상), 표(출력방식)가 전부 지정된다. 패치마다 가능한 아퀴룬이 바뀌는 게임 특성상, 이력 비교를 위해 기간 지정이 필수다.

## 질문 설계 규칙 3개

| 규칙 | 설명 |
| ---- | ---- |
| 날짜 범위를 넣으면 이력 질문이 명확해진다 | "2025년" 또는 "현재 기준"을 빼면 AI가 어느 시점 기준인지 스스로 추정하게 됨 |
| 원하는 컬럼을 미리 말하면 출력이 일정해진다 | "날짜 / 대상 / 조건"처럼 컬럼명을 지정하면 표 형식이 안정적으로 나옴 |
| "알려줘"보다 "정리해줘 + 형식 지정"이 더 정확하다 | 의도(현황 파악인지 이력 조회인지)를 분명히 할수록 불필요한 내용이 줄어듦 |
