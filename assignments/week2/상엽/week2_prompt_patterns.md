## 2. 가장 좋은 질문 버전 1개

**선정: 주제 2 V4 — "챌린저리그 보 상 알려줘"**

---

## 3. 왜 이 질문이 좋은지

첫째, "챌린저리그"라는 대상 단어가 명확해서 AI가 전체 유니버스리그가 아닌 챌린저 전용 보상에 집중해서 답했다.

둘째, V1의 "정산"이라는 단어는 의미가 여러 개(점수 정산, 상금 정산, 일정 정산)라 AI가 되물었지만, V4의 "보상"은 의미가 하나라 바로 답했다.

셋째, 오타("보 상")가 포함되어 있었음에도 AI가 정확히 인식했다. 이는 단어 선택이 오타보다 결과에 더 큰 영향을 준다는 것을 보여준다.

넷째, 다이아 상금, 보스 처치 보상, 스페셜 보상, 이벤트 보상 등 4가지 보상 유형을 모두 포함한 가장 상세한 결과를 얻었다.

다섯째, 특정 대상(챌린저리그)을 지정했을 때 AI가 마스터/플래티넘/골드/실버 리그와의 차이도 자동으로 설명해줘 비교 정보까지 얻을 수 있었다.

## 4. 질문 설계 규칙 3개

| 규칙 | 설명 | 근거 |
| ---- | ---- | ---- |
| 단어 선택이 결과를 가장 많이 바꾼다 | "정산"처럼 의미가 여러 개인 단어보다 "보상"처럼 의미가 하나인 단어를 쓸수록 원하는 답이 바로 나온다 | V1 vs V3·V4 비교 |
| 대상을 구체화하면 범위가 좁혀진다 | "유니버스리그" 대신 "챌린저리그"처럼 하위 대상을 지정하면 AI가 그 대상에 집중해서 더 깊이 있는 답을 준다 | V1 vs V4 비교 |
| 줄임말·오타·구어체는 결과에 거의 영향이 없다 | "유니", "보 상", "언제 받?" 등 형식이 달라도 AI는 의미를 정확히 파악했다. 형식보다 단어 선택이 더 중요하다 | V2·V3·V4 전체 실험 |

## 5. CLI 검색 실행 결과 (유니버스리그 주제, 4건)

### V1: "유니버스리그 정산 알려줘"

```
DB에서 찾은 자료 정리해 드립니다. DB에 들어있는 최신 시즌은 시즌12 (2026-03-11 ~ 03-31)이며,
그 이후(시즌13) 안내는 DB에 아직 수집되어 있지 않습니다.
"정산"이 여러 의미로 쓰여서 맥락별로 정리합니다.

1) 점수 정산 시점
2) 라운드/시즌 일정 = 정산(상금 지급) 기준일
3) 다이아 상금 정산

→ 마지막에 "어떤 정산을 알고 싶으신가요? (A/B/C)" 되물음
```

### V2: "유니 정산 알려줘"

```
핵심만 간결히:
- 점수 정산: 거점전 선포 종료 후 1시간 뒤 합산
- 상금 정산: 각 라운드 종료 시 챌린저 참가 팀에 지급 (라운드당 50만 다이아)
시즌12 기준 라운드 종료일 표 출력 (라운드1~3)

→ 되묻지 않고 바로 요약해서 답변
```

### V3: "유니버스 리그 보상 언제 받?"

```
DB 기준 유니버스리그 보상 지급 시점:
- 다이아 상금: 각 라운드 종료 시
- 보스 처치 전설 아퀴룬: 즉시 드롭
- 시즌 종료 특별 선물: 우편함 지급
- 제전 보상: 미션 달성 즉시

→ "보상"으로 단어 바꾸니 지급 유형이 다이아 상금 외에 보스 보상·제전 보상까지 확장됨
```

### V4: "챌린저리그 보 상 알려줘" (오타 포함)

```
챌린저 리그 보상:
1) 다이아 상금 (챌린저 전용, 라운드당 50만 다이아)
2) 보스 처치 전설 아퀴룬 (챌린저/마스터 전용, 보스별 드랍 목록 표 출력)
3) 스페셜 보상 (챌린저1~3 등급별 확률 표)
4) 보스 처치 이벤트 보상 (조각·심연석 등)

→ 오타에도 정확히 인식. 챌린저 전용 정보로 범위가 좁혀져 가장 상세한 결과
```

### AI 채팅 vs CLI 비교 메모

- CLI는 DB를 직접 쿼리해서 답하기 때문에 패치노트에 없는 정보(시즌13 등)는 명확히 "없음"이라고 답한다.
- AI 채팅은 학습 데이터 기반으로 추정해서 답할 수 있어 최신 정보가 없어도 그럴듯한 답을 줄 수 있다.
- 정확한 이력·날짜·규칙 검색은 CLI(DB 기반)가 더 신뢰도가 높다.
